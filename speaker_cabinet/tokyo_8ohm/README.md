# Tokyo Cone 8 Ohm Speaker Cabinet

This folder stores the cabinet work for the Tokyo Cone F12E28A01-1 oval speaker.

## Speaker

- Model: F12E28A01-1
- Type: 30 x 70 mm oval speaker
- Impedance: 8 ohm
- Use here: low-profile ESP32 radio integrated cabinet
