## 18650電池化の手持ち候補

2026-06-06に、手持ち部品写真から以下を電池駆動の試作候補として選ぶ。

| 部品 | 写真上の識別 | 用途 | 判断 |
|---|---|---|---|
| XL6009E1昇圧モジュール | `XLSEMI XL6009E1`、青基板、可変抵抗付き | 18650の3V台を5Vへ昇圧 | 手持ち昇圧モジュールがこれ1個のため試作に使う。ESP32接続前に必ずテスターで5.0V前後へ調整する |
| 緑TP4056 USB-C基板 | `4056E`、`DW01A`、`8205A`、`B+` / `B-` / `OUT+` / `OUT-` 表記 | 1S Li-ion充電と保護出力 | 青TP4056より良い候補。保護IC付きに見え、電池端子と負荷端子が分かれているため試作ではこちらを使う |

この構成はpower pathではない。まずは「電源OFFで充電し、使用時は充電USBを外す」運用で試す。充電しながら常用する完成版にする場合は、load sharing / power path対応の1S充電昇圧モジュールを別途検討する。

## 完成後の筐体改善メモ

- 電源スイッチ穴は実機では超音波カッターで後加工した。次回の3Dプリント筐体では、電源スイッチ位置を確定して最初から穴を入れる。
- USB充電口も次回の3Dプリント筐体で最初から穴を入れる。現行TP4056のUSB-C、または将来の1S Li-ion充放電統合モジュールのType-C入力へアクセスできる位置にする。
- OLED右下がスピーカー側と干渉したため、実機ではディスプレイ基板を少し切り取って逃がした。次回はOLEDをもう少し左へ寄せ、スピーカーとのクリアランスを増やす。

## ESP32-S3

`ESP32-audioI2S` はPSRAMを必要とするため、PSRAM付きESP32-S3を前提にする。今回の実物写真では `ESP32-S3-WROOM-1 N16R8` の刻印を確認したため、初期実験の第一候補はこのボードにする。

推奨:

- ESP32-S3-N8R8
- ESP32-S3-N16R8
- ESP32-S3-WROOM-1-N16R8

次回確認すること:

- 実ボードの型番は写真上では `ESP32-S3-WROOM-1 N16R8`。PlatformIO/Arduino側からもFlash/PSRAM認識を確認する。
- USB/JTAGや起動ストラップと競合しないGPIO。
- ネイティブUSB Deviceを使える配線/USBポートか。

## MAX98357A

MAX98357AはI2S入力を受けるモノラルClass-Dアンプ。初期実験では1個だけ使い、左右mixまたは片ch出力で小型スピーカーを鳴らす。

注意:

- `SPK+` / `SPK-` はBTL出力で、どちらもGNDへ接続しない。
- 大音量では電流不足によるリセットや音割れが起きやすい。
- GAINとSD/MODEはまずモジュール既定で試す。

## スピーカー

購入済み:

- 2インチ級 / 53mm フルレンジスピーカー。
- 定格インピーダンス: 4Ω。
- 定格出力: 3W。
- 4個セット。

MAX98357Aは3W級のモノラルClass-Dアンプなので、初期実験の組み合わせとして適している。
最初は音量を低めにし、音割れ、ビビり、ESP32-S3のリセットが出ないか確認する。

商品画像から読み取った寸法・仕様:

| 項目 | 値 |
|---|---|
| 正面外形 | 約52.6mm |
| 直径表記 | 53mm |
| 側面幅表記 | 約39.4mm |
| 側面高さ表記 | 約28.5mm |
| 高さ表記 | 30mm |
| 形状 | 円形 |
| 定格出力 | 3W |
| 定格インピーダンス | 4Ω |
| 周波数応答 | 商品画像では `170kHz` 表記。一般的な小型スピーカー仕様としては要再確認 |
| 感度 | 100 dB/W |
| 信号対雑音比 | 商品画像では `1dB` 表記。スピーカー仕様としては要再確認 |
| 高調波歪み | 商品画像では `1 TMD%` 表記。THD表記の可能性があるため要再確認 |

注意:

- スピーカーは `SPK+` / `SPK-` に接続する。
- `SPK-` をGNDへ落とさない。
- 2個のMAX98357Aでステレオ化する案もあるが、最初は1個のモノラルで十分。
- 商品ページ由来の周波数応答や歪み表記は不自然な可能性があるため、設計では4Ω / 3W / 約53mmの実装寸法を優先する。

## pi_radioから引き継ぐ考え方

- 常用局は WNYC / BBC Radio 4 / ABC NewsRadio の3局にする。NHK R1は配信方式変更と暗号化HLSの可能性があるため、操作UIには出さない。
- OLEDには局名、状態、IP、音量を出す。
- OLEDは `pi_radio` と同じ GM009606v4.3 を使い、`SSD1306 128x64 / I2C 0x3C` として扱う。
- ロータリーは回転で音量、短押しで局切替を基本にする。

移植しないもの:

- Linux systemd。
- NetworkManager。
- `shutdown -h now` による安全停止。
- USB DAC / PAM8403 構成。
